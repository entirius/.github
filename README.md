# entirius/.github

Organization-wide GitHub defaults for the `entirius` org. Files here apply to every
repository that does not provide its own version.

| Path | Purpose |
|---|---|
| `profile/README.md` | Organization profile shown on the org page |
| `CONTRIBUTING.md` | Default contribution guidelines |
| `CODE_OF_CONDUCT.md` | Default code of conduct (Contributor Covenant 2.1) |
| `SECURITY.md` | Default security / vulnerability disclosure policy |
| `SUPPORT.md` | Where to get help |
| `.github/pull_request_template.md` | Default pull request template |
| `.github/ISSUE_TEMPLATE/` | Default issue templates |

A repository that ships its own copy of any of these overrides the default.
`CODEOWNERS`, `LICENSE`, and repo `README.md` are **not** inherited — keep those per-repo.

This repository must be **public** for the defaults to apply to public repositories.
