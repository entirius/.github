# Code of Conduct

Short version: be a professional.

## The rules

- **Argue about code, not about people.** Hard technical criticism is welcome — make it
  about the patch, back it with reasons, and take it as well as you give it.
- **No harassment, no personal attacks, no trolling.** This protects everyone, full
  stop — we're not going to enumerate humanity to prove we mean it.
- **Don't publish other people's private information.** Ever.
- **Keep project spaces about the project.** Issues, PRs, and discussions are for
  building an e-commerce platform, not for politics or crusades of any flavor.
- **Assume good faith first.** Most "wrong" code is missing context, not malice.

## When someone breaks them

Report it to [opensource@entirius.com](mailto:opensource@entirius.com). Maintainers read
every report, keep the reporter confidential, and respond within a few business days.

The response is proportional: a private word for a bad day, a warning for a pattern,
a temporary or permanent ban for anyone who treats this project as a place to abuse
people. Maintainers moderate content that crosses these lines and their call is final.

## Scope

All project spaces in the `entirius` organization — repositories, issues, pull
requests, discussions — and anywhere you're officially representing the project.
