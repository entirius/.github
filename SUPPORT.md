# Support

Where to go depends on what you need.

- **Learn the platform** — [docs.entirius.com](https://docs.entirius.com). Architecture,
  module docs, guides, API reference. Most "how do I" questions end here.
- **Something is broken** — open a bug report in the repository of the module that broke.
  The template asks for a traceback and a way to reproduce; both make the fix faster.
- **An idea** — open a feature request. We read every one; the roadmap is still ours —
  see [CONTRIBUTING](CONTRIBUTING.md) for the honest version of that deal.
- **Security issue** — do **not** open a public issue. Follow the
  [Security Policy](SECURITY.md).

What support here is not: a help desk for your deployment. Issues are for the platform,
not for individual stores. First response within a few business days; beyond that, no
warranty and no SLA — this is open source, not a support contract.
