# Support

Need help with an Entirius project?

- **Documentation** — start with the repository's `README.md`.
- **Questions and ideas** — open a GitHub Discussion (where enabled) or a `question` issue.
- **Bugs and feature requests** — open an issue using the provided templates.
- **Security vulnerabilities** — do **not** open a public issue; follow the [Security Policy](SECURITY.md).

This is open-source software provided without warranty. Response times depend on
maintainer availability.
