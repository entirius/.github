# Entirius

Open-source, modular e-commerce platform built on Django and Django REST Framework.

Entirius is composed of small, independently released building blocks:

- **`entirius-py-*`** — reusable Python libraries.
- **`entirius-django-*`** — reusable Django modules (apps).
- **`entirius-service-*`** — deployable backend services that orchestrate the modules.

## Principles

- **Open source** under the Mozilla Public License 2.0 (open-core friendly).
- **English-only** across code, docs, and history.
- **Modern Python toolchain**: uv, ruff, pytest, pre-commit.
- **git-flow** with `master` (production) and `develop` (integration).
